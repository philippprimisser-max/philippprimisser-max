### Hi, I'm Philipp (Vienna)

I build small, offline-first tools around podcasts and transcripts, and write down what I measure along the way.

**Open source (MIT)**
- [podcast-to-text](https://github.com/philippprimisser-max/podcast-to-text): transcribe a podcast episode locally from its RSS feed or Apple Podcasts link.
- [faster-whisper-gap-check](https://github.com/philippprimisser-max/faster-whisper-gap-check): find speech that is missing from a Whisper transcript.
- [whisper-word-captions](https://github.com/philippprimisser-max/whisper-word-captions): word-by-word highlighted captions with faster-whisper and ffmpeg.
- [ted-tender-alerts](https://github.com/philippprimisser-max/ted-tender-alerts): new EU public tenders from the official TED API, by CPV code and country.
